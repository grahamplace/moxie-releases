# Moxie releases

Downloads and the Sparkle update feed for [Moxie](https://buy.polar.sh/polar_cl_5KXQolQefn3X6xpcMtP8K97tPqOnpqeTY74vE0Dl6R6), a voice mock interviewer for macOS.

- Every DMG is an asset of the [`updates` release](https://github.com/grahamplace/moxie-releases/releases/tag/updates).
- `appcast.xml` (served at https://grahamplace.github.io/moxie-releases/appcast.xml) is written by `scripts/release/direct.sh` in the Moxie source repo. Don't edit it by hand.
